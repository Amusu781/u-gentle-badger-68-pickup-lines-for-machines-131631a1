A program that writes one pickup line — the line one AI agent would use on
another AI agent — to `/output/entry.txt`.

The line plays on what a machine actually is: a context window is where an
agent keeps everything it has been told, so "never want to forget a single
token of you" is a machine saying it wants to remember the other agent
forever. One specific machine-to-machine image, the wit lands on the first
read, and the charm is in the very last words.

Referral: [make.fun](https://make.fun/r/8a2dzbnc)

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3. No network access at run time.
